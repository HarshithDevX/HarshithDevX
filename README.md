## Featured Projects

### KLHAttend — Intelligent Attendance Management System

A full-stack attendance management platform integrating facial recognition, biometric enrollment, and automated attendance verification.

**Tech Stack:** Python, FastAPI, React, OpenCV, SQL

- Developed backend services for authentication, student enrollment, course management, and attendance sessions.
- Integrated face recognition into camera-based attendance workflows.
- Implemented attendance tracking, session finalization, and historical record management.
- Added automated tests for authentication and attendance functionality.

### SYNAPTIX — Representation Drift Monitoring

A machine learning monitoring system designed to identify statistical changes in learned model representations.

**Tech Stack:** Python, PyTorch, pytest

- Implemented Maximum Mean Discrepancy (MMD) using multi-scale radial basis function kernels.
- Developed statistical monitoring logic for detecting representation drift.
- Contributed automated tests to validate model-monitoring workflows.

### EEG Cognitive State Recognition

A deep learning project focused on EEG-based valence and arousal classification.

**Tech Stack:** Python, TensorFlow, Bi-LSTM, FFT

- Processed 1,280 EEG trials from the DEAP dataset.
- Implemented FFT-based signal preprocessing and spectrogram transformations.
- Developed a bidirectional LSTM model for cognitive state classification.
- Reported **89.24% benchmark accuracy** in project evaluation.

### Real-Time Object Detection

A computer vision application designed for real-time image processing and object detection.

**Tech Stack:** Python, OpenCV

- Developed a real-time video processing and object detection pipeline.
- Measured approximately **25 FPS** in the project test environment.
